# Reports

Progress and project reports for CS 413 (MMK).

| Folder / file | What goes in it |
|---|---|
| `weekly/` | One weekly update per week, named `YYYY-MM-DD.md` (the Monday of that week), copied from `weekly/TEMPLATE.md` |
| [`../docs/DESIGN_REPORT.md`](../docs/DESIGN_REPORT.md) | Design report: paradigm per component, what we would change |
| [`../docs/AI_USE_LOG.md`](../docs/AI_USE_LOG.md) | AI-use log with verifiers |
| [`../docs/AUDIT.md`](../docs/AUDIT.md) | System audit and test results |
| [`../docs/ACCESS_TEST_TABLE.md`](../docs/ACCESS_TEST_TABLE.md) | Access test table (generated from the Prolog rules) |

Weekly updates are also posted in the Kaneo project; the file here is the record that stays with the code.
